# HiveOS Command & Conquer Theme

A Command & Conquer / Red Alert inspired UI theme for HiveOS.

![HiveOS Command & Conquer](assets/screenshots/hiveos-command-conquer.png)

## Features

- Red Alert / Command & Conquer command-center interface
- Dark industrial UI
- Red/yellow status indicators
- C&C-style navigation
- Command-center header
- CRT/scanline effects
- Custom background support
- C&C music player
- Automatic theme reapplication after HiveOS navigation
